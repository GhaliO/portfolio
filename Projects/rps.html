RPS Gesture Recognition

How it works
  • Use MediaPipe to detect 21 hand landmarks per frame
  • Gestures classified via simple geometric rules / features
  • Optimized for low latency and smooth interaction
Tools Used
Python MediaPipe OpenCV NumPy

  • Game UX and feedback loop
  • Performance tuning
