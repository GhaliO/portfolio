GrooveCircle

Community chatroom for music lovers with Spotify OAuth and MongoDB-backed profiles.

What it does

Users sign in with Spotify, chat in rooms, and sync playlists. Back end stores user profiles and preferences in MongoDB.

Key Features
  • Spotify OAuth login and token refresh
  • MongoDB schema for users and sessions
  • Playlist sync and real-time chat
Tools Used
Node.js Express MongoDB Spotify API JWT / OAuth
My Role
  • Auth flow with Spotify OAuth
  • Database design & CRUD endpoints
  • Chatroom features and logging
